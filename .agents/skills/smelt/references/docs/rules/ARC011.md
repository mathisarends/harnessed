# ARC011 architecture/unknown-layer

A feature contains a package or module outside the declared layers.

- **Category:** architecture
- **Activation:** default — Enabled by default.
- **Severity when active:** error
- **Automatic fix:** none; repair by hand
- **Guide:** Place feature code inside one of the declared layers

## Why

Code outside the layer grid is invisible to every layer rule: voice/models/ or voice/helpers.py can import anything and be imported by anything. A feature's __init__.py is fine, and not every feature needs every layer.

## Bad

```python
voice/
  domain/
  application/
  models/      # not a layer
  helpers.py   # in no layer
```

## Good

```python
voice/
  domain/
    models.py
  application/
```

## How to fix

Move the code into a declared layer, or assign its package to the intended layer. Use the layer's modules list for packages outside features.

## Config

- `architecture.layers`
- `architecture.layers.<layer>.modules`

Explain it in the terminal with `smelt explain ARC011`.
