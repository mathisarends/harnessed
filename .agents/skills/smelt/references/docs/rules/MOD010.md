# MOD010 modeling/implicit-duration-unit

A numeric duration is named without its unit or written as an inline number.

- **Category:** modeling
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** warning
- **Automatic fix:** none; repair by hand
- **Guide:** Put the unit in duration names (timeout_seconds) or use timedelta; avoid inline numbers

## Why

A constant called _FRAME_TIMEOUT = 2.0 does not say whether it means seconds or milliseconds, and asyncio.timeout(2.5) at two call sites drifts apart as soon as one of them is tuned. This opt-in review reports two forms. Names (kind constant, field or parameter): module constants, class fields and function parameters whose name ends in timeout, delay, interval, duration or wait and that hold a number: an int or float annotation, possibly wrapped in Final, ClassVar, Optional, Annotated or | None, or an unannotated int or float literal. Names that end in a unit, such as _TIMEOUT_SECONDS or quiet_ms, and values typed as timedelta are valid; @overload and @override signatures are not checked. Literals (kind literal): int and float literals passed as the duration of asyncio.timeout, asyncio.sleep, asyncio.wait_for, asyncio.wait, time.sleep and the anyio and trio sleep and timeout scopes, resolved through imports and aliases, and literals added to a clock reading such as loop.time() + 10 or time.monotonic() + 10. Ruff's PLR2004 only covers comparisons. sleep(0), which yields control instead of waiting, and tests are not checked.

## Bad

```python
_FRAME_TIMEOUT = 2.0


async def settle(page):
    async with asyncio.timeout(2.5):
        await page.settle()
```

## Good

```python
_FRAME_TIMEOUT_SECONDS = 2.0
SETTLE_TIMEOUT_SECONDS = 2.5


async def settle(page):
    async with asyncio.timeout(SETTLE_TIMEOUT_SECONDS):
        await page.settle()
```

## How to fix

Append the unit to the name, e.g. _SECONDS or _ms, and convert once where the value enters the code, or type the value as datetime.timedelta. Move an inline duration into a module constant or configuration field whose name states its purpose and unit, and reuse it at every call site that means the same wait. No automatic rewrite is performed. Enable rules: {modeling/implicit-duration-unit: warning}, or select MOD010.
