# MET002 meta/missing-suppression-reason

An inline suppression without a `-- reason`.

- **Category:** meta
- **Activation:** default — Enabled by default.
- **Severity when active:** error
- **Automatic fix:** none; repair by hand
- **Guide:** Give every smelt suppression comment a -- reason

## Why

Every exception to the architecture should explain itself, so the next person (or agent) knows whether it can be removed.

## Bad

```python
from app.infra import Db  # smelt: ignore[ARC001]
```

## Good

```python
from app.infra import Db  # smelt: ignore[ARC001] -- migration tracked in #123
```

## How to fix

Append ` -- <reason>` to the comment.

## Config

- `suppressions.require_reason`

Explain it in the terminal with `smelt explain MET002`.
