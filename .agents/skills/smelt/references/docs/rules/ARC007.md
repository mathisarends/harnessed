# ARC007 architecture/non-public-module-import

Code outside a contracted package imports a private implementation module.

- **Category:** architecture
- **Activation:** explicit — Enable by rule setting or --select; requires that a package API declares public entry points, including an explicitly empty public list.
- **Severity when active:** error
- **Automatic fix:** none; repair by hand
- **Guide:** Import a contracted package only through its public entry points

## Why

Explicit entry points keep callers coupled to a package's supported interface. Internal imports and intentional symbol re-exports through public facades remain valid. Wiring and composition roots still obey these contracts. Discovered tests, including conftest.py and tests inside the contracted package's configured test roots, are outside callers and must use the public API. With `test_access: mirrored`, a test whose tests.mirror path mirrors a module of the package counts as inside it and may import its private modules; conftest.py and other tests stay outside. Test-quality exclusions do not exempt imports; project exclusions and normal suppressions apply. Layer and feature policies apply independently.

## Bad

```python
# app/client.py
from app.orders.storage import OrderStore
```

## Good

```python
# app/client.py
from app.orders.api import place_order
```

## How to fix

Import through one of the contract's public entry points. Expose a deliberate API there if needed, or explicitly revise the contract. Public entries are exact module patterns; add .** only when the whole subtree is intentionally public.
