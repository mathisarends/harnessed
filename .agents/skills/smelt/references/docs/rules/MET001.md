# MET001 meta/unused-suppression

An inline suppression is unused or names an unknown identifier.

- **Category:** meta
- **Activation:** default — Enabled by default.
- **Severity when active:** warning
- **Automatic fix:** some findings carry a fix
- **Guide:** Remove suppressions that no longer match a finding

## Why

Stale suppressions hide future violations on the same line and make readers believe there is an exception where there is none. Inline comments accept rule names, codes and code prefixes, like YAML and the CLI. Unknown identifiers, including retired rule names, are diagnosed with their replacement even in narrowed checks when MET001 is selected. Known inactive rules are not treated as unknown.

## Bad

```python
import os  # smelt: ignore[architecture/layer-boundary] -- legacy
```

## Good

```python
import os
```

## How to fix

Remove the comment, or the unused codes from it. check --fix removes unused suppressions and unused identifiers, keeping the reason while other identifiers remain, and replaces retired rule names and codes with their successors. Other unknown identifiers carry a suggested removal that --fix never applies: correct a misspelled identifier instead where the comment is still needed.

## Config

- `suppressions.require_reason`

Explain it in the terminal with `smelt explain MET001`.
