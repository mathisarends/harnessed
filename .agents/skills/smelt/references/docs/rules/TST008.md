# TST008 tests/unbounded-wait

A known test wait has no local deadline, or the scheduler clock is replaced.

- **Category:** tests
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** warning
- **Automatic fix:** none; repair by hand
- **Guide:** Bound every wait in tests with a timeout

## Why

A wedged subprocess or known Event.wait can hang a suite. This opt-in review aid checks subprocess.run/call/check_call/check_output and typed Popen wait/communicate calls for their own timeout, and awaited asyncio Event/Task/Future or subprocess Process waits for enclosing wait_for or timeout contexts. Async processes come from awaited create_subprocess_exec/shell factories or explicit Process annotations, including known fixture returns. Each wait/communicate needs its own guard; an earlier bounded read or a preceding kill does not bound a later exit wait. Configured qualified timeout helpers can supply guards. One direct call to an unambiguous, undecorated, non-generator same-file helper is followed, including nested helpers and async helpers explicitly awaited or passed to asyncio.run. Findings identify the operation inside that helper and its caller. An enclosing caller deadline can bound async waits but never a synchronous subprocess. Uncalled definitions, unexecuted coroutines, callbacks, imported helper bodies, further helper calls, fixture execution, external test-runner deadlines and general task flow remain outside inference. Replacing the time method on a known running asyncio loop is reported separately because deadlines on that same clock can stop too. Controlled domain clocks, positive sleeps and sleep(0) yields are not prohibited.

## Bad

```python
def test_import():
    subprocess.run([sys.executable, '-c', 'import app'], check=True)
```

## Good

```python
def test_import():
    result = subprocess.run([sys.executable, '-c', 'import app'], capture_output=True, timeout=10, check=False)
    assert result.returncode == 0, result.stderr
```

## How to fix

Use a timeout at the blocking process boundary or around a known async wait. When replacing the scheduler clock, retain an independent real-time guard such as a parent-process timeout. Preserve bounded polling at real external boundaries. Findings sharing the same helper operation and diagnosis form a shared_helper presentation group with one repair and every affected test call site. JSON retains individual findings and identities; grouping does not change suppression, debt, severity totals or changed/staged scope.
