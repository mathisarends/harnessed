# LAY012 layout/redundant-comment

A comment or docstring only restates the name it documents.

- **Category:** layout
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** hint
- **Automatic fix:** none; repair by hand
- **Guide:** Write comments that add a reason or constraint, not ones that restate the name

## Why

A comment that repeats the name below it adds reading time and no information, and it drifts once the code changes. This opt-in hint compares words, not meaning. It checks the standalone comment block directly above a def, a class or an assignment to a single name, and the whole docstring of a module, class or function. Names and comments are split at punctuation, underscores and CamelCase humps and lowercased. Articles, prepositions and filler words (a, an, the, of, for, to, by, with, get, return, returns, this, class, function, method, helper, module, value, ...) are dropped, and plurals and third-person verbs are stemmed lightly (users and creates lose their s, entries becomes entry). The comment is reported when every remaining word is a word of the name, and never when no word remains. A docstring that goes on to document arguments, raised exceptions or behavior adds words and is not reported. Comment blocks with tool directives, license text, TODO/FIXME markers, section dividers or links are left alone, as are trailing comments. Paraphrases with synonyms are out of scope. Commented-out code, untracked TODOs and dividers are Ruff's ERA001, TD003 and FIX002. Tests are not reported.

## Bad

```python
# Get user by id
def get_user_by_id(user_id: UserId) -> User: ...

class OrderRepository:
    """Repository for orders."""
```

## Good

```python
# Cached because the upstream API is rate limited.
def get_user_by_id(user_id: UserId) -> User: ...

class OrderRepository:
    """Orders by customer; archived orders are never returned."""
```

## How to fix

Say why the code exists or what is non-obvious about it, or remove the comment. When layout/module-docstring-convention or idioms/missing-interface-docstring requires the docstring, the finding says so: write a better docstring instead of removing it. No source is rewritten. Enable rules: {layout/redundant-comment: hint}, or select LAY012.
