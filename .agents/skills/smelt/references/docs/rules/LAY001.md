# LAY001 layout/forbidden-module-name

A package or module name is listed in style.forbidden_names.

- **Category:** layout
- **Activation:** explicit — Enable by rule setting or --select; requires that style.forbidden_names contains naming restrictions.
- **Severity when active:** error
- **Automatic fix:** none; repair by hand
- **Guide:** Name modules after what they do, never with a forbidden generic name

## Why

Names like utils or helpers describe nothing, so everything fits in them. They grow into grab bags that every layer imports.

## Bad

```python
voice/application/utils.py
```

## Good

```python
voice/application/durations.py
```

## How to fix

Name the module after what it does, or move each function next to its callers.

## Config

- `style.forbidden_names`

Explain it in the terminal with `smelt explain LAY001`.
