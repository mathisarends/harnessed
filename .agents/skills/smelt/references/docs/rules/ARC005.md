# ARC005 architecture/shared-imports-feature

A shared or central module imports a feature module.

- **Category:** architecture
- **Activation:** explicit — Enable by rule setting or --select; requires that architecture.shared or a layer module binding declares shared/central modules.
- **Severity when active:** error
- **Automatic fix:** none; repair by hand
- **Guide:** Keep shared and central modules independent of feature modules

## Why

Shared code and central layers such as a platform package are importable by every feature. If they depend on a feature, every feature transitively depends on that feature and the slices collapse. With architecture.import_graph.transitive, paths through arbitrary project helpers and facades are checked and reported with a shortest import chain.

## Bad

```python
# gateway/shared/money.py
from gateway.features.billing.domain import Currency
```

## Good

```python
# gateway/shared/money.py
class Currency: ...
```

## How to fix

Move the needed concept into shared, or move the shared code into the feature.

## Config

- `architecture.shared`
- `architecture.layers.<layer>.modules`
- `architecture.import_graph.transitive`
- `architecture.import_graph.type_checking`

Explain it in the terminal with `smelt explain ARC005`.
