# ARC014 architecture/missing-required-module

A package is missing a required module or public entry point.

- **Category:** architecture
- **Activation:** explicit — Enable by rule setting or --select; requires that a package API requires modules or named public entry points.
- **Severity when active:** error
- **Automatic fix:** none; repair by hand
- **Guide:** Provide the modules and public entry points the package contract requires

## Why

Explicit package APIs let contributors and agents follow the same structure. They apply only to matching packages and require no particular framework, feature layout or layer names. Excluded code does not fulfill a contract. This checks presence, not implementation quality.

## Bad

```yaml
architecture:
  packages:
    slices:
      match: app.slices.*
      required: [api]   # app.slices.orders.api is absent
```

## Good

```yaml
architecture:
  packages:
    slices:
      match: app.slices.*
      required: [api]   # every matching package has an api module or package
```

## How to fix

Implement the missing module in the matching package. If that package should follow a different structure, narrow or split the contract. Do not add empty implementation stubs solely to satisfy the check.

## Config

- `architecture.packages`

Explain it in the terminal with `smelt explain ARC014`.
