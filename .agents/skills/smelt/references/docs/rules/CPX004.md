# CPX004 complexity/duplicate-function

A module-level function repeats another function's code.

- **Category:** complexity
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** warning
- **Automatic fix:** none; repair by hand
- **Guide:** Reuse an existing function instead of copying it; share one copy from a common module

## Why

Copy-pasted helpers drift: a fix or a changed message lands in one copy and the others keep the old behavior, and readers cannot tell whether the difference is intended. This opt-in review compares module-level functions within each analyzed root package and reports every function whose parameters, annotations, decorators and body are identical to another one's, ignoring names, docstrings, comments and formatting. A body needs at least three statements, counting nested ones, so trivial one-liners are not reported. Methods, nested functions, test files and separate root packages are not compared. Each copy gets its own finding with the other locations.

## Bad

```python
# app/tools/keyboard.py
def _secret_entered(exact: bool) -> Effect:
    if exact:
        return Effect("Text entered.")
    return Effect("Text entered with a slip.", break_chain=True)

# app/tools/typing.py
def _secret_entered(exact: bool) -> Effect:
    if exact:
        return Effect("Text entered.")
    return Effect("Text entered with a slip.", break_chain=True)
```

## Good

```python
# app/tools/effects.py
def secret_entered(exact: bool) -> Effect:
    if exact:
        return Effect("Text entered.")
    return Effect("Text entered with a slip.", break_chain=True)

# app/tools/keyboard.py and app/tools/typing.py
from app.tools.effects import secret_entered
```

## How to fix

Keep one copy in a module both callers may import, usually in their nearest common package, and import it from there. Check architecture boundaries and import cycles when choosing the owner. Copies that must evolve independently keep a reasoned suppression. No automatic rewrite is performed. Enable rules: {complexity/duplicate-function: warning}, or select CPX004.
