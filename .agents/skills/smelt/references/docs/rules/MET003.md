# MET003 meta/resolved-debt

A debt entry that no longer matches any violation.

- **Category:** meta
- **Activation:** default — Enabled by default.
- **Severity when active:** warning
- **Automatic fix:** none; repair by hand
- **Guide:** Prune resolved debt with smelt debt --prune

## Why

Fixed violations should leave the debt file, otherwise they could silently come back.

## Bad

```python
{"code": "ARC001", "path": "app/application/old.py", ...}
```

## Good

```python
(entry removed after the violation was fixed)
```

## How to fix

Run `smelt debt --prune`.

## Config

- `debt`

Explain it in the terminal with `smelt explain MET003`.
