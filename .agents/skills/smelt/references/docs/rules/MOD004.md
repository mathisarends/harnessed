# MOD004 modeling/str-enum-value-convention

A StrEnum spells its values against the configured auto/explicit convention.

- **Category:** modeling
- **Activation:** explicit — Enable by rule setting or --select; configurable when style or a package override sets str_enum_values.
- **Severity when active:** hint
- **Automatic fix:** some findings carry a fix
- **Guide:** Follow the package's StrEnum value convention (explicit strings or auto())

## Why

StrEnum values follow one project convention, chosen with str_enum_values. explicit (the default) keeps every value visible where it is declared, so renaming a member cannot silently change a serialized value; a member using auto() is reported. auto treats auto() as the convention because it derives the lowercased member name: an explicit string repeating that name is noise and hides which values are deliberate wire contracts. Under auto, a class with custom values such as 'mouseMoved' keeps explicit strings for every member and its auto() members are reported instead. It considers production classes inheriting directly from enum.StrEnum (imported as StrEnum, an alias or enum.StrEnum). Member aliases, private names and tests are ignored.

## Bad

```python
# style: {str_enum_values: explicit}
class SignalingMessageType(StrEnum):
    DESCRIPTION = auto()
    READY = auto()
```

## Good

```python
class SignalingMessageType(StrEnum):
    DESCRIPTION = "description"
    READY = "ready"
```

## How to fix

Under explicit, spell each reported auto() member as its lowercased name, the value auto() produces for a StrEnum. Under auto, replace each reported explicit string with auto(), or spell the auto() members of a class with custom values explicitly. check --fix rewrites the reported members and adds or removes the auto import; a class that overrides _generate_next_value_ is left for a manual edit. Enable rules: {modeling/str-enum-value-convention: hint}, select MOD004, or set str_enum_values under style or in a style override. Reasoned inline suppressions are supported.

## Config

- `rules`
- `style.str_enum_values`
- `style.overrides`

Explain it in the terminal with `smelt explain MOD004`.
