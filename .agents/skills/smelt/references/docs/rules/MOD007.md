# MOD007 modeling/prefer-project-base-class

A class inherits an outside base directly instead of the project base.

- **Category:** modeling
- **Activation:** explicit — Enable by rule setting or --select; requires that style or a package override sets bases, including {}.
- **Severity when active:** warning
- **Automatic fix:** none; repair by hand
- **Guide:** Inherit the project base class instead of the configured outside base

## Why

Projects often wrap a framework base in their own base class to share configuration, for example a pydantic BaseModel subclass that sets extra='forbid' and frozen=True. A class that inherits the framework base directly silently misses that configuration, and nothing in the class tells a reviewer. A style override maps each outside base to the project base, e.g. bases: {pydantic.BaseModel: app.core.Options}, and production classes in the package that list the outside base among their direct bases are reported. Bases are resolved through the module's imports, including aliases and module attributes. Only inheritance is judged: importing the outside base for annotations, isinstance checks or adapters stays valid. The module that defines the project base is exempt, a nested package can set bases: {} to allow direct inheritance, and single classes can keep a reasoned suppression. Tests are not checked.

## Bad

```python
from pydantic import BaseModel, ConfigDict

class Manifest(BaseModel):
    model_config = ConfigDict(extra="forbid")
```

## Good

```python
from app.core.options import Options

class Manifest(Options):
    ...
```

## How to fix

Inherit the project base named in the finding and drop configuration that only repeated it. When a class deliberately needs the outside base, keep a reasoned suppression or move it into a package whose contract sets bases: {}. No automatic rewrite is performed. Enable it for the project with style: {bases: {pydantic.BaseModel: app.core.Options}}, or for one package with the same option in a style override.

## Config

- `style.bases`
- `style.overrides`
