# ARC012 architecture/unclassified-module

A module maps to no feature, layer, shared set or composition root.

- **Category:** architecture
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** warning
- **Automatic fix:** none; repair by hand
- **Guide:** Place every module in a feature, a layer, the shared set or the composition root

## Why

Unclassified modules are exempt from layer and feature boundary checks: a domain module may import them. Composition-root/wiring restrictions and configured cycle checks still apply. Central code such as a database or storage package can be assigned to a layer's modules list. Root packages with no classified module at all (libraries) are skipped.

## Bad

```python
gateway/
  platform/db.py    # neither shared, a layer nor a feature
```

## Good

```python
# smelt.yml
architecture:
  modules:
    gateway.platform: infrastructure
```

## How to fix

Add the package to the intended layer's modules list, list it in architecture.shared or composition_root, or move it into a feature.

## Config

- `architecture.layers.<layer>.modules`
- `architecture.shared`
- `architecture.composition_root`

Explain it in the terminal with `smelt explain ARC012`.
