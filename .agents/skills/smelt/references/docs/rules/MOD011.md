# MOD011 modeling/mutable-field-in-frozen-dataclass

A frozen dataclass directly declares a mutable collection field.

- **Category:** modeling
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** warning
- **Automatic fix:** none; repair by hand
- **Guide:** Use tuple, frozenset or a read-only mapping for fields of frozen dataclasses

## Why

frozen=True prevents rebinding fields, but list, dict and set contents can still change, including through a reference passed to the constructor. This opt-in ownership review reports each directly annotated built-in dict, list or set instance field on a dataclass explicitly decorated with frozen=True. It resolves module/import aliases and quoted annotations, conservatively skipping names bound again anywhere in the file, local imports and wildcard imports. ClassVar, InitVar, inherited fields, wrapped/union annotations, user-defined types and type aliases are outside its scope. Non-frozen classes and tests are ignored. A Mapping annotation is a read-only interface, not proof of runtime or deep immutability. Intentional mutable reference holders can keep a reasoned field suppression.

## Bad

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Arguments:
    names: dict[str, str]
```

## Good

```python
from collections.abc import Mapping
from dataclasses import dataclass
from types import MappingProxyType

@dataclass(frozen=True)
class Arguments:
    names: Mapping[str, str]

    def __post_init__(self) -> None:
        object.__setattr__(self, "names", MappingProxyType(dict(self.names)))
```

## How to fix

Review ownership. Use tuple or frozenset for immutable sequences/sets. For a mapping, copy before wrapping it in MappingProxyType: wrapping the caller's original dict alone still reflects alias mutations. Changing only the annotation to Mapping freezes nothing. Copying or freezing may change behavior, so no automatic rewrite is performed. Enable rules: {modeling/mutable-field-in-frozen-dataclass: warning}, or select MOD011.
