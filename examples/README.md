# Examples

The examples form a learning path in three stages. Read each stage in numeric order:

1. [`getting_started/`](getting_started): an agent, a tool and a stream.
2. [`applications/`](applications): approvals, sessions, context, subagents and operations.
3. [`plugin_authoring/`](plugin_authoring): tools, hooks, dependency injection, lifecycles and the kernel.

Run one from the repository root:

```bash
uv run python -m examples.getting_started.01_tool_agent
```

The [examples guide](../docs/guides/examples.md) describes every example.
